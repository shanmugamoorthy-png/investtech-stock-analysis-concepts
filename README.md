# Investtech Stock Analysis Concepts

A browsable reference of the stock analysis concepts listed on [investtech.com](https://www.investtech.com): timeframes, signals, price structure, screening, portfolio tools and education.

- `concepts.json` – the data (category, summary, detailed explanation points, source link)
- `index.html` – searchable page with a suggested learning path, concept explanations and a glossary (open locally, or via GitHub Pages)

Summaries are written in my own words. Not affiliated with Investtech; not investment advice.

## Scanner and backtest
The `scanner/` folder applies simplified versions of these concepts to NSE data from the Dhan API. Its backtest found no usable predictive edge; see `scanner/README.md` for the results and caveats.
